# Programs that CANNOT link on wasm32-wasip1, and the symbol each fails on.
#
# A skip is a hole in coverage. This file is what makes each one deliberate:
# crates/run_test_corpus.sh compares the actual skip set to this list EXACTLY
# and fails the build on any difference — a new skip, a removed one, or the
# same program skipping for a different reason. There is no regeneration flag;
# editing this file is meant to be a reviewed act.
#
# Every entry below is blocked on a capability wasm32-wasip1 does not have, not
# on unfinished work:
#
#   __osprey_coro_suspend       resumable effect continuations — the handler
#                               runs the suspended computation on its own
#                               thread; wasm32-wasip1 has no usable pthreads.
#                               [WASM-TARGET-EFFECTS]
#   fiber_spawn_env_owned       fibers, same reason. `fiber_sleep` entries also
#                               spawn and await; sleep is merely the first
#                               unresolved symbol the linker names.
#   http_create_server          HTTP/WebSocket — BSD sockets, absent from WASI
#   http_create_client          preview1 (sockets arrive in preview2).
#   http_get_response
#   http_response_body
#   spawn_process_with_handler  subprocesses — no fork/exec under WASI.
#   osprey_ffi_cell             FFI — no dlopen under WASI.
#
# Anything portable has been ported: file I/O and the OS CSPRNG moved into the
# wasm runtime archive rather than staying on this list. Shrink it further by
# porting a capability, never by loosening the check.
