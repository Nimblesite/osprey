# Perception Website

Standalone Eleventy website for **Perception** (formerly Prism), built directly on the native DAW's visual design system (`#100D21` studio indigo, `#FF8442` signal orange, `#AA9EE6` modulation lavender, `#4FDAD3` monitor cyan, plus full light/dark `color-scheme` support).

## Commands

```sh
npm install
npm run build   # builds static site into _site/
npm run dev     # local dev server with live reload
```

Screenshots are copied from `../screens/` at build time by Eleventy passthrough copy, keeping the website self-contained when Perception moves to its own repository.
