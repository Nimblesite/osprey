# Talon typography

Talon bundles Inter 4.1 from [the Inter project](https://github.com/rsms/inter/tree/v4.1) (`docs/font-files/InterVariable.ttf` at tag `v4.1`), unmodified and licensed under the SIL Open Font License in `Inter-OFL.txt`. Frames name it as `frameFont = "Inter"`, and every host loads it from this folder ([UI-COMPONENTS-FRAMED]).
