A commit is the smallest unit of trust. When every edit is one, the history of the site reads like a diary: who changed what, when, and why.

## Save is not publish

Saving records the change. Publishing pushes the saved commits to the repository the site is built from. Keeping them apart means an editor can work for an hour, review the history, and only then put it live.

1. Edit in Formatted or Markdown mode.
2. Save: one commit.
3. Publish: the pipeline rebuilds the site.
