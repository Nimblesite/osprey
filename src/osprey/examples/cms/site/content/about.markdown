# About the studio

Northwind is three people, two dogs and one very old espresso machine. We design and build software for teams who would rather be doing their real work.

## How this site works

The developers built the site in Eleventy and handed it over. Everything you read here lives in a git repository as Markdown and media, and the editors change it in **Osprey Studio**: saving makes a commit, and publishing pushes it, which rebuilds the site.

> Good tools disappear. You notice the work, not the tool.
