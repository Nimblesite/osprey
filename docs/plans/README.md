# Implementation plans

Active plans track unfinished language, runtime, tooling and ecosystem work. Retired plans are struck through; their contracts and acceptance evidence live in the linked specifications. Retirement records the source accepted at that time, not fresh validation of later changes. Remaining requirements belong to an active plan or a specification's status section.

| [0012](0012-osprey-debugger.md) | Modern Osprey debugger | compiler/editor/runtime | Native DWARF and real LLDB-DAP launch are implemented. Source lambdas and extracted host kernels carry scopes, primitive parameters, captures and return-line locations, including single-expression bodies. Materialized generic function values and C/runtime callbacks retain source names and parameters. Generic specialization preserves declaration scope, caller evaluation order and independent nested type instantiations. Both-flavor LLDB-DAP tests inspect direct/resumable handler parameters and live shared cells across mutations. Match arms now retain primitive binding scopes and block return locations; both-flavor debugger tests verify shadowing and scope exit. Ordinary nested blocks and binding initialization now preserve lexical visibility. Native build controls select metadata, unoptimized compilation and retained artifacts; editor launches can select a compiler. Native field inspection covers named, anonymous, generic and C ABI records, including parameters, captures and live cells. Explicit console selection supports Debug Console output and integrated/external terminals with a verified LLDB-DAP 21+ adapter. Remaining work includes optimized/unavailable values, union/Result/collection renderers, object graphs, concurrency inspection and replay. | High |
