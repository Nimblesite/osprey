# Osprey review

This is the one review for the repository. It holds only critical findings: memory safety, security, silent wrong answers, failures that break [FAILURE-EXPLICIT], soundness holes, and tests or gates that were loosened. Everything else is a GitHub issue, listed in [Moved to GitHub](#moved-to-github). A finding is deleted once it is fixed; earlier versions are in git history.

Each status below was checked against `origin/main` at `3329a783d` (v0.28.2 plus #336–#339 and #343) on 2026-11-06:

- **Open**: the defect was reproduced on that date, or seen in the code.
- **Unchecked**: a lead not yet confirmed. Reproduce it first.

Reproductions used macOS on Apple silicon. Nothing in this review was run on Linux, Windows or Android.

**Fix these first:**
- [GPU helpers take the kernel's parameters on Metal](#gpu-and-staged-effects): a silently wrong answer.
- [The native store escapes through symlinks](#runtime-and-security).
- [Windows GC skips data and BSS roots](#runtime-and-security).
- [VS Code focus fails on macOS, a platform CI never runs it on](#regressions-and-loosening-since-v0282) (#344).

## Regressions and loosening since v0.28.2

This section comes from a static review of v0.28.2 → `3329a783d` on 2026-11-06, covering 6,073 files and five squash merges. Two deepseek-flash pis read the assertion-level diffs, and every pi verdict listed here was confirmed against the diff.

**Method.** The review covered:
- assertion counts in every moved, modified or deleted test file;
- added `ignore`, `skip`, `xfail`, `continue-on-error` and `|| true`;
- paired numeric changes to timeouts, thresholds and budgets;
- coverage thresholds key by key;
- the `ci.yml` job set, the required `CI` job's `needs`, and job and step `if:` conditions;
- deslop excludes and the duplication cap;
- every changed `.expectedoutput`;
- deleted tests and goldens with no destination.

## Hunt

CI skips `clean.osp` by name (`HUNT_KNOWN_BUGS`, `scripts/make/tests.mk`), and the defect itself is #306. **Open.** The remaining phases are in [plan 0034](../plans/0034-symbolic-execution.md).

**Constraints.** `--max-solver-time=30s` with the forked solver is mandatory: in-process, the solver explored 6 paths and completed only 1. **Do not retry** these, which all measured neutral or worse and were reverted at `f6085332`:
- a raw-view bounded parse;
- an O(n) min-reduction line copy;
- a `gc_scan_range` alignment filter;
- a binary-search digit length in `hunt_format.c`.

**Evidence, 2026-10-26.**
- `clean.osp` needs about 49 s of solver work against a 30 s budget.
- `--solver-backend=z3 --solver-optimize-divides` cut partial states from 18 to 3 under GC and from 19 to 3 under ARC.
- `make _test_hunt_mock`: 948,770 checks, 0 failures.
- `make _test_hunt_crashes`: 15/15.
- Corpus sweep of 215 programs: 168 fully explored with no findings, 47 refused (#307), 0 planted findings.

## Standard for closing a finding

A higher percentage closes nothing. The closing test must come from a named spec obligation and prove the observable contract:
- exact values;
- every rejection, including boundary cases;
- side effects, and their absence;
- ownership across cleanup;
- exit status;
- parity across the CLI, runtime, LSP, native, ML and wasm.
