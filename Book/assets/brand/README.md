# Brand assets

The canonical Osprey mark is the shaded cyan banking osprey at [website/src/assets/images/logo.png](../../../website/src/assets/images/logo.png). Book production references that file rather than creating a divergent logo copy. The HTML reading copy embeds the same mark through `header.html`; the EPUB carries it on the cover.

The cover's generated PNG composites the canonical mark onto the deterministic SVG master. Editorial illustrations may use an abstract osprey flight motif but never replace or redraw the product mark.
