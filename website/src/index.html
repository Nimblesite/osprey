04 / Bring your Python thinking

Port your Python.
Put the computation on the GPU.

Keep def, lambda, and f-strings. Port computation into Osprey’s Python flavor with inferred types and checked effects. Keep Python libraries through explicit interop.

GPT-2 is the worked port: one Tensor effect, a CPU handler, and a GPU handler using Metal or OpenCL. The handler decides where the arithmetic runs.
